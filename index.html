The physics

The simulator applies Newton’s law of universal gravitation, resolves the force into x and y components, and updates velocity and position every frame.

02

The implementation

The original desktop project uses Pygame, a cached star polygon, and a bounded deque for an efficient orbit trail.

The experiment

Adjust gravity, mass, and starting velocity to see a stable orbit become elliptical, escape the star, or collapse inward.

# Newtonian gravity
force = (G * M_STAR * M_PLANET) / distance_squared

force_x = force * dx / distance
force_y = force * dy / distance

acceleration_x = force_x / M_PLANET
acceleration_y = force_y / M_PLANET
